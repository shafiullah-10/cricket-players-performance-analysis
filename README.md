# Cricket Players Performance Analysis

An interactive cricket players performance analysis dashboard built using Python and Streamlit.

## Project Overview

This project analyzes cricket player performance data and presents the results through an interactive dashboard.

Users can explore player statistics, compare players, apply filters, and understand performance trends using different visualizations.

## Features

- Player performance analysis
- Player comparison
- Interactive filters
- Minimum matches filter
- Performance statistics
- Interactive charts
- Data visualization
- KPI summary
- Easy-to-use Streamlit interface

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib

## Dataset

The project uses structured cricket player performance data for analysis and visualization.
